Название проекта
Конвертер валют «Быстрый обмен»
🎯 Основная задача
Создать консольную программу, которая переводит фиксированную сумму денег из одной валюты в другую по заранее заданному (захардкоженному) курсу.
📋 Требования к функционалу
Выбор направления: Программа предлагает пользователю выбрать режим конвертации (например, 1 — из Долларов в Рубли, 2 — из Рублей в Доллары).
Ввод суммы: Программа запрашивает сумму для перевода (число с плавающей точкой).
Фиксированный курс: Внутри кода должны быть объявлены константы курса (например, 1 = 90 рублей).
Вывод результата: Программа рассчитывает и выводит итоговую сумму с указанием валюты.
🛠 Используемые инструменты и концепции C++
Переменные и константы: double, ключевое слово const.
Ввод-вывод: std::cin, std::cout.
Логика: управляющая конструкция if-else или switch для выбора режима обмена.
💡 Пример работы программы
=== КОНВЕРТЕР ВАЛЮТ === 1. Доллары в Рубли 2. Рубли в Доллары Выберите режим (1-2): 1 Введите сумму в долларах: 150 Результат обмена: 13500.00 рублей. 
🧪 Список тестов для проекта «Конвертер валют»
1. Позитивные тесты (Проверка базовой логики)
Для тестов примем курс: 1 USD = 90 RUB.
Тест 1.1: Конвертация USD ➡️ RUB
Действия: Выбрать режим 1, ввести сумму 100.
Ожидаемый результат: 9000 (или 9000.00).
Тест 1.2: Конвертация RUB ➡️ USD
Действия: Выбрать режим 2, ввести сумму 4500.
Ожидаемый результат: 50 (или 50.00).
Тест 1.3: Работа с дробными числами
Действия: Выбрать режим 1, ввести сумму 1.5 (доллара).
Ожидаемый результат: 135 (или 135.00).
2. Граничные тесты
Тест 2.1: Нулевая сумма
Действия: Выбрать любой режим, ввести сумму 0.
Ожидаемый результат: 0 (Программа не должна падать или выдавать ошибки).
Тест 2.2: Минимальная дробная часть
Действия: Выбрать режим 2, ввести сумму 0.9 (90 копеек).
Ожидаемый результат: 0.01 (1 цент). Если программа вывела 0, значит, вы неверно округляете или используете целые числа int вместо double.
3. Негативные тесты (Обработка ошибок)
Тест 3.1: Ввод неверного режима
Действия: На шаге выбора режима ввести число 3 (или 0, -1).
Ожидаемый результат: Сообщение об ошибке: «Неверный режим работы!» и завершение программы (либо повторный запрос).
Тест 3.2: Ввод отрицательной суммы
Действия: Выбрать режим 1, ввести сумму -50.
Ожидаемый результат: Программа должна выдать ошибку (например: «Сумма не может быть отрицательной!») вместо того, чтобы возвращать отрицательный баланс.
