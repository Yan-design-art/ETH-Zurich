📋 Требования к функционалу
Ввод данных: Программа запрашивает у пользователя вес в килограммах (число с плавающей точкой) и рост в метрах (например, 1.75).
Расчет ИМТ: Программа вычисляет индекс по стандартной формуле:
ИМТ = вес / (рост)^2 
Анализ результата: Программа проверяет, в какой диапазон попадает ИМТ:
Меньше 18.5 — Дефицит массы тела.
От 18.5 до 24.9 (включительно) — Нормальный вес.
От 25.0 до 29.9 (включительно) — Избыточный вес.
30.0 и более — Ожирение.
Вывод: Программа выводит точное значение ИМТ (округленное до сотых) и текстовый вердикт.
🛠 Используемые инструменты и концепции C++
Переменные: double для высокой точности веса, роста и самого индекса.
Ввод-вывод: std::cin, std::cout.
Логика: Конструкция if - else if - else для разделения на 4 медицинские категории.

🧪 Список тестов для проекта «Калькулятор ИМТ»
1. Позитивные тесты (Проверка всех диапазонов)
Тест 1.1: Дефицит веса
Входные данные: Вес = 50, Рост = 1.80 (ИМТ ≈ 15.43)
Ожидаемый результат: Вердикт: Дефицит массы тела.

Тест 1.2: Норма
Входные данные: Вес = 70, Рост = 1.75 (ИМТ ≈ 22.86)
Ожидаемый результат: Вердикт: Нормальный вес.

Тест 1.3: Избыточный вес
Входные данные: Вес = 85, Рост = 1.75 (ИМТ ≈ 27.75)
Ожидаемый результат: Вердикт: Избыточный вес.

Тест 1.4: Ожирение
Входные данные: Вес = 100, Рост = 1.70 (ИМТ ≈ 34.60)
ожидаемый результат: Вердикт: Ожирение.

2. Граничные тесты (Стыки категорий)
Тест 2.1: Точная граница нормы (низ)
Входные данные: Подобрать вес и рост так, чтобы ИМТ был равен ровно 18.5 (например, вес = 59.2, рост = 1.79, ИМТ ≈ 18.48 -> округлим до точных: вес = 53.28, рост = 1.696)
Ожидаемый результат: Программа должна отнести это к «Нормальному весу» (если в коде стоит >= 18.5).

Тест 2.2: Точная граница нормы (верх)
Входные данные: ИМТ равен ровно 24.9.
Ожидаемый результат: Программа должна написать «Нормальный вес» (если в коде стоит <= 24.9).
3. Негативные тесты (Защита от некорректных данных)

Тест 3.1: Нулевой или отрицательный рост
Входные данные: Вес = 70, Рост = 0 (или -1.75)
Ожидаемый результат: Сообщение об ошибке: «Рост должен быть больше нуля!» (Защита от деления на ноль и нереалистичных данных).

Тест 3.2: Перепутанные данные (Рост в сантиметрах)
Входные данные: Вес = 70, Рост = 175 (пользователь ввел сантиметры вместо метров).
Ожидаемый результат: Так как ИМТ получится микроскопическим (70 / 175² = 0.0022), хорошая программа должна выдать ошибку: «Пожалуйста, введите рост в метрах (например, 1.75)».
