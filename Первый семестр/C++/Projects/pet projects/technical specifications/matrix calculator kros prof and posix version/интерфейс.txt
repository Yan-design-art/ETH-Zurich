================================================================
               ОПЕРАЦИИ НАД МАТРИЦЕЙ А
================================================================

  Текущая матрица А:

  |  1.00  -2.00   4.50 |
  |  0.00   3.00  -1.00 |
  |  5.00   0.00   2.00 |

    1. Найти детерминант (определитель)
    2. Транспонировать матрицу
    3. Найти обратную матрицу (A^-1)
    4. Найти ранг матрицы
    5. Возвести в степень N
    6. Изменить элементы матрицы
    7. Назад в главное меню

 Выберите действие [1-7]: _

5. РЕШЕНИЕ СЛАУ (ScreenState::SlauSolver)
----------------------------------------------------------------
================================================================
               РЕШЕНИЕ СИСТЕМЫ УРАВНЕНИЙ (СЛАУ)
================================================================

  Введенная система уравнений:
  /  2.0*X1  +  3.0*X2  -  1.0*X3  =   7.0
  |  0.0*X1  +  1.0*X2  +  5.0*X3  =  -2.0
  \  4.0*X1  -  2.0*X2  +  0.0*X3  =   1.5

  Выберите метод решения:
    1. Метод Гаусса (Универсальный)
    2. Метод Крамера (Через определители)
    3. Матричный метод (X = A^-1 * B)
    4. Назад

----------------------------------------------------------------
 Выберите метод [1-4]: _

7. ОКНО КРИТИЧЕСКОЙ ОШИБКИ (ScreenState::ErrorWindow)
----------------------------------------------------------------
================================================================
               ВНИМАНИЕ: ОШИБКА ВЫЧИСЛЕНИЙ!
================================================================

  [!] Невозможно выполнить операцию умножения матриц.

  Причина:
  Число СТОЛБЦОВ первой матрицы (сейчас: 3) должно быть строго
  равно числу СТРОК второй матрицы (сейчас: 4).

  Текущие размеры:
  Матрица А: 2 x 3
  Матрица В: 4 x 2

----------------------------------------------------------------
 Нажмите [Любую клавишу], чтобы вернуться к выбору действий...

8. РАБОТА С ФАЙЛАМИ (ScreenState::FileInputOutput)
----------------------------------------------------------------
================================================================
               РАБОТА С ТЕКСТОВЫМИ ФАЙЛАМИ
================================================================

  Вы хотите загрузить Матрицу А из внешнего файла.

  Правила:
  Убедитесь, что файл находится в папке с программой.
  Первая строка файла должна содержать: [строки] [столбцы].
  Далее должны идти сами числа через пробел.

  Введите точное имя файла (например, data.txt):
  > input_matrix.txt
