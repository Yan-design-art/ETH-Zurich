## Техническое задание: Консольная анкета «Выбор пути»

## 1. Описание задачи
Необходимо разработать консольное приложение на C++, которое приветствует пользователя, предлагает выбрать один из двух вариантов развития сюжета нажатием одной клавиши (без использования Enter) и позволяет вернуться обратно в главное меню.
## 2. Функциональные требования

* Главное меню:
* Программа должна вывести на экран приветствие и меню:
   * Нажмите 1 — Посмотреть баланс игрока
      * Нажмите 2 — Посмотреть имя персонажа
      * Нажмите 0 — Выйти из программы
   * Программа должна мгновенно реагировать на нажатие клавиш 1, 2 или 0 (без ожидания клавиши Enter).
   * Любые другие нажатые клавиши должны игнорироваться.
* Ветвление (Функции):
* При нажатии 1 программа очищает экран и вызывает функцию showBalance(). Она выводит текст: "Ваш баланс: 1000 золотых монет".
   * При нажатии 2 программа очищает экран и вызывает функцию showCharacter(). Она выводит текст: "Имя персонажа: Конан-Варвар".
* Навигация «Назад»:
* Находясь внутри функций showBalance или showCharacter, внизу экрана должно быть написано: "Нажмите [Esc] для возврата в меню".
   * При нажатии на клавишу Esc (ASCII код 27) функция завершается, экран очищается, и пользователь снова видит Главное меню.

------------------------------
## 3. Технические требования

* Язык программирования: C++ (стандарт C++20 / C++26).
* Кроссплатформенность: Код должен без изменений компилироваться и работать как на Windows (через <conio.h>), так и на macOS / Linux (через <termios.h>).
* Очистка экрана: Переключение между меню и функциями должно сопровождаться очисткой консоли с помощью ANSI-последовательности \033[2J\033[1;1H.
* Архитектура: Логика перехвата клавиши должна быть вынесена в отдельную функцию getKeyPress(), чтобы не дублировать код.

------------------------------
## 4. Критерии успешного выполнения (Чек-лист для проверки)

   1. При запуске выводится главное меню.
   2. Нажатие цифры 1 СРАЗУ (без Enter) переключает экран на баланс.
   3. Нажатие цифры 2 СРАЗУ переключает экран на имя персонажа.
   4. Нажатие Esc внутри любого подменю возвращает вас точно в Главное меню.
   5. Нажатие цифры 0 в Главном меню закрывает программу.
   6. Если нажимать любые другие кнопки (буквы, пробел), программа не падает и не пишет ошибок.
