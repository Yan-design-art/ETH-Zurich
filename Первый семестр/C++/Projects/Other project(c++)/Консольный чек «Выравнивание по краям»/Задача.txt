## Техническое задание: Консольный чек «Выравнивание по краям»## 1. Описание задачи
Необходимо разработать программу на C++, которая имитирует вывод товарного чека из двух строк. Пользователь вводит количество купленного товара и его общую стоимость. Программа должна вывести эти данные друг под другом внутри декоративных рамок, прижав количество влево, а стоимость — вправо.
## 2. Функциональные требования

* Ввод данных: Программа должна запросить у пользователя четыре целых числа:
1. Количество первого товара (например, 5)
   2. Стоимость первого товара (например, 1500)
   3. Количество второго товара (например, 120)
   4. Стоимость второго товара (например, 80)
* Динамическое выравнивание:
* Программа должна вычислить длину самого длинного числа среди всех введенных.
   * Полученная длина становится шириной (WIDTH) для каждой текстовой ячейки.
* Формат вывода: Строки чека выводятся в рамке из символов вертикальной черты |.
* Первый столбец (Количество) прижимается влево.
   * Второй столбец (Стоимость) прижимается вправо.

------------------------------
## 3. Технические требования

* Язык: C++.
* Инструменты форматирования: Обязательно использование <iomanip> (setw, left, right).
* Расчет ширины: Для определения количества знаков в числах необходимо использовать перевод числа в строку через std::to_string() и подсчет символов с помощью .length() или .size().

------------------------------
## 4. Пример работы программы (Чек-лист для проверки)
Входные данные:

Товар 1 (Кол-во и Цена): 5 1500
Товар 2 (Кол-во и Цена): 120 80

Логика программы:
Самое длинное число здесь 1500 (4 символа). Значит, ширина каждой ячейки (WIDTH) автоматически становится равна 4.
Итоговый вывод на экран:

ЧЕК:

| 5    1500 |
| 120    80 |

(Пояснение: В первой строке после 5 идет 3 пробела, а перед 1500 пробелов нет. Во второй строке после 120 идет 1 пробел, а перед 80 — 2 пробела. Столбцы идеально ровные).
