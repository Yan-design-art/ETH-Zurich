## Техническое задание: Таблица финансовых транзакций## 1. Описание задачи
Необходимо разработать консольное приложение на C++, которое принимает от пользователя историю денежных переводов (ID транзакции и сумму) и выводит её в виде аккуратного финансового отчета. Каждый столбец должен автоматически подстраиваться под размер хранящихся в нем данных. Поля между ID и Суммой должны заполняться точками. [2, 3] 
## 2. Функциональные требования

* Ввод данных:
1. Сначала программа запрашивает у пользователя количество транзакций $N$.
   2. Затем в цикле $N$ раз запрашивает два значения: ID транзакции (целое число) и Сумму (дробное число, баланс).
* Математическая обработка и форматирование:
* Все суммы должны выводиться строго с двумя знаками после запятой (копейки).
   * Программа должна вычислить максимальную ширину отдельно для столбца ID (widthID) и отдельно для столбца Суммы (widthAmount). [2, 4] 
* Правила выравнивания при выводе:
* Столбец ID прижимается влево.
   * Столбец Суммы прижимается вправо.
   * Свободное пространство между столбцами внутри строки должно заполняться символом точки .. [1, 3, 4] 

------------------------------
## 3. Технические требования

* Язык программирования: C++ (стандарт C++20 или выше).
* Библиотеки: Управление выводом должно осуществляться через <iomanip> (std::setw, std::setfill, std::left, std::right, std::fixed, std::setprecision).
* Хранение данных: Так как количество транзакций заранее неизвестно, для хранения данных необходимо использовать std::vector динамической структуры (или два параллельных вектора). [1, 4] 

------------------------------
## 4. Пример работы программы (Чек-лист для проверки)
Входные данные:

Введите количество транзакций: 3
Транзакция 1 (ID и Сумма): 7 1500.5
Транзакция 2 (ID и Сумма): 1024 8.25
Транзакция 3 (ID и Сумма): 45 120450.99

Логика программы:

   1. Самое длинное число в столбце ID — это 1024 (4 символа). Значит, widthID = 4.
   2. Самая длинная сумма с учетом двух знаков после запятой — это 120450.99 (9 символов). Значит, widthAmount = 9.
   3. Суммы переводятся в формат fixed с setprecision(2). Число 1500.5 превращается в строку 1500.50 (7 символов). [2, 4] 

Итоговый вывод на экран:

ОТЧЕТ:
[ 7.......1500.50 ]
[ 1024.........8.25 ]
[ 45.....120450.99 ]

(Обратите внимание: ID выровнены по левому краю своей невидимой колонки шириной 4, Суммы — по правому краю колонки шириной 9, а все пустые места заняты точками).
