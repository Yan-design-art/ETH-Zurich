## 📋 Техническое задание: «Торговый автомат с динамическим ассортиментом»## 1. Описание задачи
Вы разрабатываете симуляцию торгового автомата для игры. При самом первом обращении к автомату он должен один раз случайным образом сгенерировать цены на свои товары (например, из-за изменения курса валют в игровой экономике). При всех последующих вызовах цены должны оставаться фиксированными, а игрок должен иметь возможность покупать эти товары, тратя свой баланс кошелька.
## 2. Требования к реализации

* Тип функции: Логика обрабатывается в функции void operateVendingMachine(int action, int& player_gold). Обратите внимание: баланс игрока передается по ссылке (&), чтобы функция могла уменьшать его золото при покупке.
* Использование static:
* Внутри функции должен быть static-контейнер для цен товаров. Проще всего использовать массив из 3-х элементов или static std::vector<int> item_prices.
   * При первом вызове заполните этот массив тремя случайными числами (цены на три товара: Чипсы, Газировка, Шоколад). Диапазон цен: от 15 до 50 золотых.
   * Также используйте static bool is_stocked = true, чтобы проверить, не закончились ли товары (необязательно, но добавит глубины).
* Логика внутри функции (switch-case по параметру action):
* Если action == 0 (Посмотреть меню): Функция выводит текущие (сгенерированные в первый раз) цены на все 3 товара.
   * Если action == 1, 2 или 3 (Покупка товара 1, 2 или 3):
   * Функция проверяет, хватает ли у игрока золота (player_gold >= item_prices[action-1]).
      * Если хватает: вычитает цену из player_gold и выводит: «Вы купили товар %имя%! Оставшееся золото: %баланс%».
      * Если не хватает: пишет: «Недостаточно золота! Нужно %цена%, у вас есть %баланс%».
   
## 3. Сценарий работы программы (Main)
В функции main создайте переменную int my_gold = 100; (стартовый капитал игрока) и сымитируйте шаги:

   1. Вызовите operateVendingMachine(0, my_gold); — Посмотреть меню (цены генерируются и выводятся).
   2. Вызовите operateVendingMachine(0, my_gold); — Посмотреть меню еще раз (убеждаемся, что цены не изменились!).
   3. Вызовите operateVendingMachine(1, my_gold); — Попытка купить первый товар. Программа должна успешно уменьшить my_gold.
   4. Выведите в main текущее значение my_gold, чтобы доказать, что баланс игрока изменился во внешнем коде.

## 4. Ожидаемый результат в консоли (пример, если рандом выдал цены: 20, 45, 30)

[Автомат]: Ассортимент обновлен! Цены на сегодня: Чипсы: 20, Газировка: 45, Шоколад: 30
[Автомат]: Текущие цены: Чипсы: 20, Газировка: 45, Шоколад: 30
[Покупка]: Вы купили Чипсы за 20 золотых!
[Main]: Баланс игрока после покупок: 80 золотых.

------------------------------
Что развивает это ТЗ:

* Работа с памятью: static-массив инициализируется один раз, но его элементы можно использовать многократно без утечек и перезаписи.
* Взаимодействие компонентов: передача параметров по ссылке (&) учит связывать внутреннее статическое состояние функции с внешними переменными программы (main).
