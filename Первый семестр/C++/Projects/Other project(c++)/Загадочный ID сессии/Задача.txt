## 📋 Техническое задание: «Загадочный ID сессии»## 1. Описание задачи
Необходимо написать консольную программу на C++, которая имитирует генерацию уникального ключа (ID) для игровой сессии. Программа должна генерировать случайное число ровно один раз при старте и выводить его при каждом обращении к функции, подтверждая, что число не меняется.
## 2. Требования к реализации

* Тип функции: Логика вывода должна быть оформлена в виде функции с типом возвращаемого значения void (например, void showSessionID()).
* Использование static: Внутри функции void должна использоваться static-переменная для хранения сгенерированного числа.
* Диапазон чисел: Случайное число должно быть в диапазоне от 1000 до 9999 (имитация четырехзначного ID). Можно использовать как std::rand(), так и <random>.

## 3. Сценарий работы программы (Main)
В функции main необходимо сымитировать несколько действий пользователя (например, вход в игру, сохранение и выход). Для этого:

   1. Вызовите функцию showSessionID() первый раз (произойдет генерация и вывод).
   2. Выведите в консоль текстовый разделитель (например: --- Игрок совершает действия ---).
   3. Вызовите функцию showSessionID() еще 2 раза подряд, чтобы доказать, что ID остался прежним и память не замусорилась новыми числами.

## 4. Ожидаемый результат в консоли

[Система]: Сессия создана. ID: 4572
--- Игрок совершает действия ---
[Система]: Проверка связи. ID: 4572
[Система]: Сохранение игры. ID: 4572

(Число 4572 взято для примера, у вас при каждом новом запуске всей программы оно должно быть случайным, но одинаковым внутри одного запуска).
