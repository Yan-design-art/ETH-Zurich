1. ФУНКЦИИ СТЕПЕНЕЙ И КОРНЕЙ (<cmath>)
--------------------------------------------------------------------------------
* std::sqrt(x) — Вычисляет квадратный корень из x.
  - Важно: Аргумент x не должен быть отрицательным. Иначе вернет NaN.
* std::pow(base, exp) — Возводит основание base в степень exp.
  - Важно: Функция работает с типами с плавающей точкой (float, double).

ПРАВИЛО ОПТИМИЗАЦИИ:
Для возведения числа в квадрат НЕ используйте std::pow(x, 2). 
Пишите обычное умножение: x * x. Это работает значительно быстрее (за один 
такт процессора) и исключает появление погрешности округления.


2. СРАВНЕНИЕ: std::max И std::fmax
--------------------------------------------------------------------------------
* std::max(a, b) [из библиотеки <algorithm>]
  - Универсальный шаблон для любых типов (int, string, char, структуры).
  - Требует СТРОГО одинакового типа обоих аргументов (max(5, 6.7) — ОШИБКА).
  - Плохо работает с NaN: результат зависит от порядка передачи аргументов.

* std::fmax(a, b) [из библиотеки <cmath>]
  - Предназначен ТОЛЬКО для чисел с плавающей точкой (float, double).
  - Автоматически приводит разные типы к общему типу double (fmax(5, 6.7) — ОК).
  - Безопасен с NaN: если один из аргументов NaN, функция проигнорирует его 
    и вернет корректное число.


3. ПРАВИЛА ТРИГОНОМЕТРИИ В C++ (<cmath>)
--------------------------------------------------------------------------------
ГЛАВНОЕ ПРАВИЛО: Все функции принимают и возвращают углы в РАДИАНАХ.

* Формула перевода градусов в радианы: 
  double rad = deg * (3.141592653589793 / 180.0);

* Основные функции:
  - std::sin(x), std::cos(x), std::tan(x) — синус, косинус, тангенс.
  - Котангенс пишется как: 1.0 / std::tan(x)

* Обратные функции (Арки):
  - std::asin(x), std::acos(x) — диапазон аргумента строго от -1.0 до 1.0.
  - std::atan(x) — обычный арктангенс.
  - std::atan2(y, x) — Продвинутый арктангенс. Принимает координаты отдельно.
    Важно: Первым аргументом ВСЕГДА идет 'y', вторым — 'x'. Сама определяет
    четверть круга и корректно обрабатывает деление на ноль (если x == 0).


4. ТЕРНАРНЫЙ ОПЕРАТОР
--------------------------------------------------------------------------------
Компактная замена конструкции if-else для присвоения значений или вывода.

* Синтаксис: Условие ? Выражение_1 : Выражение_2;
  Если условие истинно — возвращается Выражение_1, если ложно — Выражение_2.

* Важные правила:
  1. Выражение_1 и Выражение_2 должны возвращать данные ОДНОГО типа.
  2. Из-за низкого приоритета оператора при выводе в поток или в сложных 
     выражениях всегда берите всю тернарную конструкцию в круглые скобки:
     std::cout << (x > y ? "X больше" : "Y больше");
  3. Идеален для инициализации констант (const), которые нельзя изменить позже.

* Когда НЕ использовать: 
  Избегайте вложенных тернарных операторов (один внутри другого). Они сильно 
  ухудшают читаемость кода. В таких случаях используйте стандартный if-else.
