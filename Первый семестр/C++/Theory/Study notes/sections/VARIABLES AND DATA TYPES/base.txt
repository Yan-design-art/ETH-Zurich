               ТЕОРЕТИЧЕСКИЙ ЛИСТ: ПЕРЕМЕННЫЕ И ТИПЫ ДАННЫХ В C++

1. ЧТО ТАКОЕ ПЕРЕМЕННАЯ И ПАМЯТЬ?
-------------------------------------------------------------------------------
Переменная — это именованная ячейка в оперативной памяти (RAM) компьютера, 
в которой хранятся данные во время работы программы.

Когда в коде пишется строка "int x = 5;", происходят следующие действия:
  1. Программа запрашивает у системы объем памяти (для int обычно 4 байта).
  2. Выделенный адрес в памяти связывается с понятным человеку именем "x".
  3. В эту ячейку записывается значение "5" в двоичном коде.

Правила именования переменных (Идентификаторы):
  - Можно использовать: латинские буквы (a-z, A-Z), цифры (0-9) и "_" (подчеркивание).
  - Имя переменной НЕ МОЖЕТ начинаться с цифры (например, "1number" — ошибка).
  - C++ чувствителен к регистру: "speed", "Speed" и "SPEED" — три разные переменные.
  - Запрещено использовать ключевые слова языка (int, const, return, switch и др.).


2. БАЗОВЫЕ ТИПЫ ДАННЫХ
-------------------------------------------------------------------------------
Тип данных определяет: сколько байт займет переменная в памяти, в каком формате 
будут записаны биты и какие арифметические операции с ней можно выполнять.

Основные типы данных:
  - char        (1 байт): Один символ или ASCII-код (от -128 до 127).
  - int         (4 байта): Целое число (от -2 млрд до +2 млрд).
  - float       (4 байта): Дробное число одинарной точности (7 значащих цифр).
  - double      (8 байт): Дробное число двойной точности (15 значащих цифр).
  - bool        (1 байт): Логическое значение true (1) или false (0).

Модификаторы типов (signed / unsigned / long):
  - unsigned — убирает отрицательный диапазон. Переменная становится беззнаковой, 
    а освободившийся бит знака расширяет положительную границу (например, 
    unsigned int хранит числа от 0 до ~4.2 млрд).
  - long long — расширяет размер целого числа до 8 байт для огромных чисел.


3. ОБЪЯВЛЕНИЕ И ИНИЦИАЛИЗАЦИЯ
-------------------------------------------------------------------------------
* Объявление — резервирование места: "int age;" 
  ВНИМАНИЕ: Если локальная переменная объявлена внутри функции без значения, 
  в ней будет лежать случайный "мусор" из памяти!
* Инициализация — присвоение самого первого (начального) значения.

Способы инициализации в C++:
  int a = 5;    // C-style (классический)
  int b(5);     // Functional style
  int c{5};     // Uniform / Списочная инициализация (появилась в C++11)

ВАЖНО: Списочная инициализация "{}" — самая безопасная. Она запрещает "сужающие" 
преобразования (narrowing conversions). 
Код "int x{3.14};" вызовет ОШИБКУ компиляции, защищая от потери данных. 
Код "int x = 3.14;" скомпилируется, но молча отрежет дробную часть, оставив 3.


4. КОНСТАНТЫ (const)
-------------------------------------------------------------------------------
Если значение переменной гарантированно не должно меняться после создания, 
используют модификатор "const".

  const double PI = 3.14159;

Попытка изменить это значение ниже по коду (например, "PI = 4.0;") вызовет 
строгую ошибку компиляции. Константы обязаны инициализироваться прямо при создании.


5. БАЗОВАЯ АРИФМЕТИКА И ЛОВУШКИ ДЕЛЕНИЯ
-------------------------------------------------------------------------------
Операторы "+", "-", "*" работают стандартно. 
С оператором деления "/" нужно быть очень внимательным:

  - Если ОБА числа целые, происходит ЦЕЛОЧИСЛЕННОЕ деление (дробная часть 
    просто выбрасывается): "5 / 2" вернет "2".
  - Если ХОТЯ БЫ ОДНО число дробное, деление будет обычным математическим: 
    "5.0 / 2" или "5 / 2.0" вернет "2.5".

Оператор "%" — остаток от деления. Работает СТРОГО с целыми числами:
  "17 % 5" вернет "2" (так как 17 = 5 * 3 + 2).


6. ПРИВЕДЕНИЕ ТИПОВ (TYPE CASTING)
-------------------------------------------------------------------------------
Приведение типов — это процесс преобразования переменной из одного типа в другой.

Неявное приведение (Implicit):
  C++ выполняет его автоматически. Типы продвигаются от "узких" к "широким" 
  (например, при сложении int и double результат автоматически станет double). 
  Опасно тем, что при обратном неявном приведении данных (double в int) можно 
  случайно потерять точность без предупреждения системы.

Явное приведение (Explicit):
  Вы умышленно и жестко указываете компилятору изменить тип данных. В современном 
  C++ для базовых типов используется безопасный оператор "static_cast":

  int a = 5;
  int b = 2;
  double result = static_cast<double>(a) / b; // Временный перевод 'a' в double. 
                                              // Результат: 2.5


7. ПЕРЕПОЛНЕНИЕ ПАМЯТИ (OVERFLOW)
-------------------------------------------------------------------------------
У каждого типа данных есть свой физический предел в байтах. Если попытаться 
записать число, превышающее лимит, произойдет переполнение памяти.

  - Для беззнаковых типов (unsigned): Поведение строго определено стандартом. 
    Происходит сброс счетчика в ноль (эффект круга). Если к unsigned char 
    со значением 255 прибавить 1, переменная станет равна 0.
  - Для знаковых типов (signed int, char): Переполнение приводит к 
    Undefined Behavior (Неопределенному Поведению). На большинстве процессоров 
    число превратится в минимальное отрицательное, но стандарт языка этого 
    НЕ ГАРАНТИРУЕТ. Компилятор имеет право полностью сломать логику такого кода.


8. МАНИПУЛЯТОРЫ ВВОДА-ВЫВОДА (std::boolalpha)
-------------------------------------------------------------------------------
По умолчанию поток вывода "std::cout" отображает переменные типа bool в виде 
цифр 1 (true) или 0 (false). Поток "std::cin" также принимает только цифры.

Манипуляторы меняют этот режим работы:
  - std::boolalpha — переключает поток в ТЕКСТОВЫЙ режим. Теперь cout выводит 
    слова "true"/"false", а cin ожидает ввод буквами ("true"/"false").
  - std::noboolalpha — возвращает поток обратно в стандартный ЧИСЛОВОЙ режим.

ВНИМАНИЕ: Манипуляторы имеют "эффект памяти". Достаточно вызвать std::boolalpha 
один раз, и весь ввод-вывод bool до конца программы будет текстовым.
