1. БАЗОВЫЕ АРИФМЕТИЧЕСКИЕ ОПЕРАТОРЫ И ИХ ПРИОРИТЕТ
-------------------------------------------------------------------------------
В C++ встроены стандартные операторы: "+", "-", "*", "/" и "%".

Главная ловушка деления ("/"):
  - Если оба операнда целые (int, short), дробная часть ОТБРАСЫВАЕТСЯ.
    Пример: 5 / 2 вернет 2.
  - Если хотя бы один операнд вещественный (double, float), деление будет 
    обычным. Пример: 5.0 / 2 вернет 2.5.

Оператор остатка от деления ("%"):
  - Работает СТРОГО с целыми числами (для double используйте std::fmod).
  - Результат сохраняет знак ПЕРВОГО числа (делимого).
    Пример:  5 %  2  ->  1
            -5 %  2  -> -1
             5 % -2  ->  1

Приоритет операций (выполняются сверху вниз):
  1. Скобки "()"
  2. Умножение "*", Деление "/", Остаток "%" (выполняются СЛЕВА НАПРАВО)
  3. Сложение "+", Вычитание "-"

КРИТИЧЕСКАЯ ЛОВУШКА В КОДЕ:
Выражение "1 / 2 * sqrt(4.0)" вернет 0.0! Почему? 
Сначала выполняется "1 / 2". Так как оба числа целые, это даст 0. 
Затем 0 умножается на результат корня, итог — 0.0. 
Исправление: "1.0 / 2.0 * sqrt(4.0)".

ЛОКАЛЬНАЯ ЛОВУШКА ДЛЯ ЗНАМЕНАТЕЛЕЙ:
Формула "x = b / 2a" на C++ ДОЛЖНА записываться со скобками: "b / (2 * a)".
Если написать "b / 2 * a", то компьютер сначала разделит b на 2, 
а затем результат УМНОЖИТ на "a" (переменная "a" уйдет в числитель).


2. ПОДКЛЮЧЕНИЕ БИБЛИОТЕКИ <cmath>
-------------------------------------------------------------------------------
Для использования продвинутых математических функций в начале файла обязательно 
нужно прописать директиву:

  #include <cmath>

Все функции этой библиотеки находятся в пространстве имен "std::". Они принимают 
и возвращают преимущественно типы double или float.


3. ОСНОВНЫЕ ФУНКЦИИ БИБЛИОТЕКИ <cmath>
-------------------------------------------------------------------------------
* Степень и корень:
  - std::sqrt(x)  — Квадратный корень из x.
  - std::cbrt(x)  — Кубический корень из x.
  - std::pow(x, y)— Возведение x в степень y. 
    Опасность: Выражение "std::pow(x, 1 / 3)" вернет 1.0, так как "1 / 3" — это 
    целочисленный ноль. Нужно писать "std::pow(x, 1.0 / 3.0)".

* Модуль числа (Абсолютное значение):
  - std::abs(x)   — Универсальная функция для поиска модуля как целых чисел, 
    так и вещественных (double).

* Поиск максимума и минимума:
  - std::fmax(x, y) — Возвращает наибольшее из двух вещественных чисел.
  - std::fmin(x, y) — Возвращает наименьшее из двух вещественных чисел.

* Округление чисел:
  - std::floor(x) — Округляет ДО БЛИЖАЙШЕГО ЦЕЛОГО ВНИЗ (в меньшую сторону).
                    std::floor(2.9)  ->  2.0
                    std::floor(-2.1) -> -3.0
  - std::ceil(x)  — Округляет ДО БЛИЖАЙШЕГО ЦЕЛОГО ВВЕРХ (в большую сторону).
                    std::ceil(2.1)   ->  3.0
                    std::ceil(-2.9)  -> -2.0
  - std::round(x) — Округляет ПО МАТЕМАТИЧЕСКИМ ПРАВИЛАМ (от 0.5 — вверх).
                    std::round(2.5)  ->  3.0
                    std::round(-2.5) -> -3.0
  - std::trunc(x) — Просто ОТБРАСЫВАЕТ дробную часть, всегда округляя к нулю.
                    std::trunc(2.9)  ->  2.0
                    std::trunc(-2.9) -> -2.0


4. ТРИГОНОМЕТРИЯ И РАДИАНЫ
-------------------------------------------------------------------------------
Функции std::sin(x), std::cos(x), std::tan(x) принимают угол СТРОГО в РАДИАНАХ.

Если передать градусы напрямую (например, std::sin(90)), программа посчитает 
синус от 90 радиан (это примерно 89 оборотов круга) и выдаст неверный результат.

Формула перевода: Радианы = Градусы * (PI / 180.0)

Рекомендуемый эталон объявления константы PI в C++:
  const double PI = 3.141592653589793;


5. ЛОГАРИФМЫ И ЭКСПОНЕНТА
-------------------------------------------------------------------------------
  - std::log(x)   — Вычисляет НАТУРАЛЬНЫЙ логарифм (ln x, по основанию e).
  - std::log10(x) — Вычисляет ДЕСЯТИЧНЫЙ логарифм (lg x, по основанию 10).
  - std::exp(x)   — Возводит число e в степень x (e^x).


6. ОСОБЫЕ СОСТОЯНИЯ: NAN И INF
-------------------------------------------------------------------------------
При работе со значениями с плавающей точкой (double/float) математические ошибки 
не ломают программу мгновенно, а генерируют специальные системные значения:

* "inf" / "-inf" (Infinity — Бесконечность)
  - Возникает, например, при вычислении "std::log(0.0)" (даст -inf).
  - Также возникает при делении вещественного числа на ноль: "1.0 / 0.0" -> inf.
  - С бесконечностью можно считать: "std::exp(-inf)" выдаст абсолютно точный "0".

* "nan" (Not a Number — Не число)
  - Возникает при математической неопределенности.
  - Пример: извлечение корня из отрицательного числа "std::sqrt(-1.0)" -> nan.
  - Пример: логарифм отрицательного числа "std::log(-5.0)" -> nan.
  - Пример: деление нуля на ноль "0.0 / 0.0" -> nan.

ГЛАВНОЕ СВОЙСТВО NAN:
Значение "nan" не равно вообще ничему, даже самому себе! 
Если переменная x содержит "nan", то выражение "(x == x)" вернет false (0).
Для официальной проверки переменной на nan используйте функцию "std::isnan(x)".


7. ОШИБКА ТОЧНОСТИ ВЕЩЕСТВЕННЫХ ЧИСЕЛ
-------------------------------------------------------------------------------
Компьютер хранит числа в двоичной системе, поэтому он не может идеально точно 
записать некоторые простые десятичные дроби (например, 0.1 или 0.2).

В результате: выражение "(0.1 + 0.2) == 0.3" в C++ вернет FALSE (0)! 
В памяти сумма "0.1 + 0.2" будет равна примерно "0.30000000000000004".
Никогда не сравнивайте double через точное равенство "==".
