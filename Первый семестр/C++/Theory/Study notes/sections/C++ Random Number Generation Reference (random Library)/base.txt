     СПРАВОЧНИК ПО ГЕНЕРАЦИИ СЛУЧАЙНЫХ ЧИСЕЛ В C++ (БИБЛИОТЕКА <random>)
======================================================================

1. СОВРЕМЕННЫЙ ПОДХОД (ВМЕСТО RAND())
----------------------------------------------------------------------
Старая функция rand() устарела. В современном C++ используется библиотека 
<random>. Она работает быстрее, точнее и выдает по-настоящему случайные 
числа без повторяющихся шаблонов.

Для работы нужны три компонента:
1) std::random_device — получает «зерно» (seed) от операционной системы.
2) std::mt19937 — сам генератор (алгоритм «Вихрь Мерсенна»).
3) std::uniform_int_distribution — распределение, задающее диапазон.

Пример создания инструментов (делать строго ОДИН РАЗ на всю программу):
std::random_device rd;
std::mt19937 mt(rd);
std::uniform_int_distribution<int> dis(1, 6); // Диапазон от 1 до 6


2. ГЛАВНОЕ ПРАВИЛО: ОДИН ГЕНЕРАТОР НА ПРОГРАММУ
----------------------------------------------------------------------
НЕЛЬЗЯ создавать новые генераторы для каждого отдельного броска кубика.
Генератор std::mt19937 устроен как конвейер. При каждом обращении он сам 
сдвигается вперед и выдает новое случайное число.

ОШИБКА (избыточность и риск одинаковых чисел):
  std::mt19937 gen1(rd); int cube1 = dis(gen1);
  std::mt19937 gen2(rd); int cube2 = dis(gen2);

ПРАВИЛЬНО (эффективно и безопасно):
  int cube1 = dis(mt); // Вызов 1: генератор выдал первое число
  int cube2 = dis(mt); // Вызов 2: генератор выдал второе число


3. ЧТО ТАКОЕ «ВЫЗОВ РАНДОМА»?
----------------------------------------------------------------------
Вызовом является конструкция вида: dis(mt)
Круглые скобки после объекта распределения работают как вызов функции. 
Они приказывают программе: «Возьми генератор mt, крутани его и верни число».

Важно: Если вы запишете результат в переменную всего один раз:
  int result = dis(mt);
  int cube1 = result;
  int cube2 = result;
То в cube1 и cube2 запишется ОДНО И ТО ЖЕ число. Копирование переменной 
не запускает генератор заново. Для нового числа нужно снова писать dis(mt).


4. ЧАСТЫЕ ОШИБКИ КОМПИЛЯЦИИ
----------------------------------------------------------------------
Ошибка: generate не является членом "std::random_device"
Причина: У класса std::random_device нет встроенного метода .generate().

* Исправление 1 (если нужно просто число): 
  Пишите dis(mt) вместо вызова методов.

* Исправление 2 (если нужно автоматически заполнить массив/вектор):
  Используйте глобальную функцию std::generate из библиотеки <algorithm>:
  
  #include <algorithm>
  std::vector<int> dice(5);
  std::generate(dice.begin(), dice.end(), [&]() { return dis(mt); });


5. ШАБЛОН ДЛЯ СОХРАНЕНИЯ МНОЖЕСТВА ЧИСЕЛ
----------------------------------------------------------------------
Чтобы оперировать большим количеством случайных чисел, их записывают 
в динамический массив (вектор) через цикл:

#include <vector>
#include <random>

int count = 100000;
std::vector<int> numbers(count);

for (int i = 0; i < count; ++i) {
    numbers[i] = dis(mt); // Заполняем вектор случайными числами
}

После этого над вектором `numbers` можно проводить любые операции: 
сортировать (std::sort), искать сумму (std::accumulate) или находить 
минимум и максимум (std::minmax_element).
