1. ОБЪЯВЛЕНИЕ И ИНИЦИАЛИЗАЦИЯ ПЕРЕМЕННЫХ
--------------------------------------------------------------------------------
В C++ создать переменную и присвоить ей значение можно несколькими способами:
• В одной строке (инициализация): `int a = 5, b = 10;`
• На разных строках:
  int a = 5;
  int b = 10;
• Раздельно (сначала создание, затем присваивание):
  int a, b;
  a = 5;
  b = 10;

2. РАБОТА С МАССИВАМИ И ИНДЕКСАЦИЯ
--------------------------------------------------------------------------------
Массив — это набор элементов одного типа, расположенных в памяти друг за другом.
• Объявление с фиксированным размером: `int arr[2] = {5, 10};`
• Автоматический подсчет размера: `int arr[] = {5, 10};`

Важные правила работы:
• Отсчет всегда с НУЛЯ: первый элемент — arr[0], второй — arr[1].
• Операции выполняются через индексы: `int sum = arr[0] + arr[1];`
• Изменить размер созданного статического массива в процессе работы нельзя.

Почему отсчет начинается с 0?
• Индекс — это СМЕЩЕНИЕ (расстояние) от начала массива в памяти. Первый элемент 
  находится в самом начале, его смещение равно 0 шагов.
• Формула адреса элемента: Адрес = Начало + (Индекс * Размер_типа). Если бы 
  отсчет шел с 1, процессору приходилось бы делать лишнее вычитание: (Индекс - 1).
  Отсчет с нуля экономит такты процессора и ускоряет работу программы.

3. ПРАВИЛО ПРИСВАИВАНИЯ И ОШИБКА LVALUE
--------------------------------------------------------------------------------
• Оператор `=` — это команда действия («взять то, что справа, и положить налево»).
• Слева от знака `=` ВСЕГДА должна быть переменная (lvalue) — место в памяти.
• Справа находится значение или вычисляемое выражение (rvalue).

Ошибочная запись: `std::abs(one) = id / 1000;` // Ошибка!
Почему: Функция std::abs возвращает готовое число (например, 5). Запись 5 = ... 
невозможна, так как нельзя перезаписать значение константного числа.

Правильная запись: `one = std::abs(id) / 1000;`

4. ПЕРЕПОЛНЕНИЕ ЦЕЛОЧИСЛЕННЫХ ТИПОВ ДАННЫХ (INTEGER OVERFLOW)
--------------------------------------------------------------------------------
Каждый тип данных имеет строго ограниченный диапазон значений (размер ячейки).
• Тип `short` занимает 2 байта и вмещает числа только от -32 768 до 32 767.

Что происходит при переполнении:
Если результат математической операции превышает верхний лимит типа, компьютер 
не выдает ошибку. Счетчик «зацикливается» по кругу и уходит в отрицательную зону.

Пример:
short id_sum = one + two + three + four; 
Если сумма равна 32 768, в переменной short она превратится в -32 768. Именно 
поэтому в финальных формулах (например, при расчете score) может внезапно 
появляться минус.

Как защититься:
1. Использовать более вместительные типы данных: `int` (до ~2 млрд) или `long long`.
2. Если значения гарантированно положительные, использовать `unsigned short` 
   (сдвигает диапазон от 0 до 65 535).
3. Использовать `std::max(0, результат)`, чтобы программно запретить счету 
   опускаться ниже нуля.
