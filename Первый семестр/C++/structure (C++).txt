## 📁 01_Теория

* 📁 Книги — электронные учебники (например, Липпман, Страуструп, Прата).
* 📁 Видеокурсы — ссылки на плейлисты, методички и презентации к лекциям.
* 📁 Конспекты — ваши текстовые файлы или Markdown-заметки по сложным темам.
* 📁 Статьи_и_Ссылки — закладки, разборы фич новых стандартов (C++17/20/23).

## 📁 02_Практика

* 📁 Задачи_из_книг — папки со своим номером для упражнений из каждой главы учебника.
* 📁 LeetCode_and_Codewars — решения алгоритмических задач с платформ.
* 📁 Тестовые_скрипты — грязный код для быстрой проверки того, "как работает эта функция".
* 📁 Лабораторные — если вы учитесь в вузе или на курсах с домашними заданиями.

## 📁 03_Фреймворки_и_Библиотеки

* 📁 GUI_Qt — создание графических интерфейсов и оконных приложений.
* 📁 Gamedev_SFML_SDL — библиотеки для работы с графикой, звуком и создания 2D-игр.
* 📁 Networking_Boost_Asio — инструменты для работы с сетью и создания серверов.
* 📁 Unit_Testing_GTest — библиотека Google Test для написания тестов к своему коду.

## 📁 04_Проекты

* 📁 Консольные_игры — змейка, крестики-нолики, текстовые RPG.
* 📁 Системные_утилиты — файловые менеджеры, архиваторы, парсеры логов.
* 📁 Пет_проекты — ваши крупные идеи (например, свой калькулятор на Qt или клон Space Invaders).

## 📁 05_Инструменты

* 📁 Шпаргалки — Cheat Sheets по синтаксису, STL-контейнерам и горячим клавишам IDE.
* 📁 Конфиги_и_Скрипты — готовые файлы .gitignore, настройки CMakeLists.txt и компилятора.
* 📁 Инструкции — гайды по установке библиотек (через vcpkg/conan) и настройке IDE (VS Code, Visual Studio, CLion).
