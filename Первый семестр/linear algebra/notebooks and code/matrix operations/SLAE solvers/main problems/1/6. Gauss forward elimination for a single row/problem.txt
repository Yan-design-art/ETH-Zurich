Напишите функцию step_gauss(matrix), которая принимает расширенную матрицу matrix размера 2 x 3. Гарантируется, что matrix[0][0] == 1. Функция должна изменить вторую строку matrix[1] так, чтобы её первый элемент matrix[1][0] стал равен 0. Для этого из второй строки нужно вычесть первую строку, умноженную на начальное значение matrix[1][0]. Функция должна вернуть измененную матрицу.
