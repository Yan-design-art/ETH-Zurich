## Техническое задание (ТЗ): Разработка модуля базовых матричных операций matrix_base.py## 1. Цель проекта

Разработать программный модуль на языке Python (с использованием библиотеки numpy или без неё — на ваш выбор), реализующий фундаментальные операции линейной алгебры. Модуль должен служить основой для автоматической проверки корректности вычислений.

## 2. Требования к структуре кода

* Все задачи должны быть оформлены в виде отдельных функций.
* Названия функций должны строго соответствовать спецификации ниже.
* Функции должны возвращать результат (через return), а не просто выводить его в консоль через print.

## 3. Спецификация функций (Содержимое модуля)

   1. create_zero_matrix()
   * Вход: нет.
      * Выход: матрица (двумерный массив) размером $3 \times 3$, заполненная нулями.
   2. add_matrices(matrix_a, matrix_b)
   * Вход: две матрицы одинакового размера.
      * Выход: новая матрица, являющаяся результатом их сложения.
   3. multiply_by_scalar(matrix, scalar)
   * Вход: матрица и любое число (скаляр).
      * Выход: матрица, где каждый элемент умножен на этот скаляр.
   4. transpose_matrix(matrix)
   * Вход: матрица любого размера.
      * Выход: транспонированная матрица (строки и столбцы поменялись местами).
   5. get_main_diagonal(matrix)
   * Вход: квадратная матрица.
      * Выход: одномерный массив (или список) элементов главной диагонали.
   6. calculate_trace(matrix)
   * Вход: квадратная матрица.
      * Выход: число (сумма элементов главной диагонали).
   7. create_identity_matrix()
   * Вход: нет.
      * Выход: единичная матрица размером $4 \times 4$.
   8. get_matrix_dimensions(matrix)
   * Вход: матрица любого размера.
      * Выход: кортеж или список из двух элементов в формате (количество_строк, количество_столбцов).
   
## 4. Входные данные для самопроверки
Для тестирования функций используйте следующие матрицы:

A = [1  2]  B = [5  6] (для сложения)
    [3  4],     [7  8]

С = [10  20], k = 5(для умножения на скаляр).
    [30  40]

D = [1  2  3] (для транспонирования и размерности)
    [4  5  6]

E = [2  4  6]
    [1  3  5] (для диагонали и следа)
    [0  0  4]

## 5. Критерии приемки

* Код запускается без синтаксических ошибок.
* Функции универсальны (работают с любыми переданными матрицами нужного размера, а не только с тестовыми).
* Типы возвращаемых данных корректны (число для следа, кортеж для размеров, матрицы для остальных задач).
