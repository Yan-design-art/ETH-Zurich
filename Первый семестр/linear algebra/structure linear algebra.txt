## 1. Теория

* 📂 Книги_и_Материалы (Учебники, методички, PDF-файлы)
* 📂 Лекции (Конспекты, записи занятий, скрины досок)
* 📂 Темы (Разбивка по ключевым разделам математики):
* 📂 01_Векторы_и_Пространства (Векторы, линейная независимость, базис, размерность)
   * 📂 02_Матрицы_и_СЛАУ (Матрицы, операции над ними, решение систем уравнений)
   * 📂 03_Определители_и_Обратные_матрицы (Детерминанты, обратные и транспонированные матрицы)
   * 📂 04_Линейные_Преобразования (Линейные операторы, матрицы переходов, смена базиса)
   * 📂 05_Собственные_Значения_и_Векторы (Собственные числа, векторы, диагонализация)
* 📂 Шпаргалки (Формулы, аксиомы, карточки для запоминания)

## 2. Практика

* 📂 Домашние_Задания (Текущие ДЗ, задачи из учебников)
* 📂 Тесты_и_Экзамены (Контрольные, билеты для самопроверки)
* 📂 Ручные_Решения (Фотографии или сканы ваших вычислений в тетради)

## 3. Код_и_Автоматизация

* 📂 Скрипты (Чистые файлы с кодом, например на Python или C++)
* 📂 Операции_с_Матрицами (Умножение матриц, поиск определителя, ранг)
   * 📂 Решатели_СЛАУ (Программы для решения систем методом Гаусса или Крамера)
* 📂 Интерактивные_Блокноты (Файлы Jupyter Notebook, где код совмещен с текстом и графиками)
* 📂 Тестовые_Данные (Готовые матрицы для проверки кода — вырожденные, единичные, случайные)

## 4. Визуализация

* 📂 Проекты_GeoGebra (Файлы интерактивной геометрии)
* 📂 Графики_и_Рисунки (Сохраненные изображения проекций, осей и векторов)
* 📂 Анимации (Видео или GIF-файлы, показывающие трансформацию пространства)

## 5. Применение

* 📂 Компьютерная_Графика (3D-повороты, проекции камер, геймдев)
* 📂 Анализ_Данных_и_ИИ (Нейросети, метод главных компонент, сжатие картинок через матрицы)
* 📂 Криптография (Шифрование текста с помощью матричного умножения)
